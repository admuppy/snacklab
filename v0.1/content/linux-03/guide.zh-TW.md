# 文字處理管線

Linux 運維工作有一半是 **讀日誌**。用管道把 grep、awk、sed 三個工具串起來,幾秒鐘就能從幾十萬行日誌裡提取出答案。

實驗環境中準備了 2,000 行 Web 伺服器訪問日誌。先看看它長什麼樣。

檢視前 5 行:

```
head -5 /var/log/lab/access.log
```

- `head -5 <檔案>` — 只輸出檔案的前 5 行(與 `-n 5` 相同)。

檢視總行數:

```
wc -l /var/log/lab/access.log
```

- `wc -l <檔案>` — 統計行數(word count 的行選項)。`-w` 統計單詞數,`-c` 統計位元組數。

一行的結構(按空白分隔的欄位編號):

| 欄位 | 內容 | 示例 |
|---|---|---|
| $1 | 客戶端 IP | `192.168.14.23` |
| $6~$8 | 請求(`"METHOD path HTTP/1.1"`) | `"GET /api/users HTTP/1.1"` |
| $9 | 狀態碼 | `200` |
| $10 | 響應位元組數 | `1532` |

## 用 grep 查詢錯誤

grep 是 **挑出** 匹配模式的 **行** 的工具。來找一下伺服器錯誤(5xx)。簡單地用 `grep 500` 會把位元組數為 500 的行也匹配進來 — 必須 **只匹配狀態碼的位置**。

```
grep -E '" 5[0-9]{2} ' /var/log/lab/access.log | head
```

- `grep -E` — 擴充套件正規表示式。`5[0-9]{2}` 表示以 5 開頭的三位數字。
- `'" 5[0-9]{2} '` — 用引號和空格包住前後,只匹配狀態碼的位置。整體用單引號括起來,避免 shell 解釋。

關鍵在於加入前後文,只匹配 `"` 後面空格之後的 5xx。`-c` 只輸出匹配的行數。

任務:把 5xx 錯誤的行數儲存到 `~/work/err5xx.count`。

儲存 5xx 行數:

```
grep -Ec '" 5[0-9]{2} ' /var/log/lab/access.log > ~/work/err5xx.count
```

- `-c` — 不輸出匹配的行,只輸出 **行數**。與 `-E` 合寫為 `-Ec`。
- `> ~/work/err5xx.count` — 把這個數字儲存到檔案。

檢視儲存的值:

```
cat ~/work/err5xx.count
```

- `cat` — 輸出檔案內容,確認儲存的數字。

儲存好後點選 **[驗證]**。

## 用 awk 提取欄位與彙總

awk 是把行 **拆分成欄位** 來處理的工具。`$1` 是第一個欄位(IP)。

```
awk '{print $1}' /var/log/lab/access.log | head
```

- `awk '{print $1}'` — 把每行按空白拆分成欄位,只輸出第一個欄位(IP)。`{ }` 中是對每一行執行的動作。

再接上經典的彙總管道 `sort | uniq -c | sort -rn`,就得到了頻次表。

```
awk '{print $1}' /var/log/lab/access.log | sort | uniq -c | sort -rn
```

- `sort` — 排序,讓相同的 IP 挨在一起;`uniq -c` — 把連續的相同行合併為一行,並在前面加上計數。
- `sort -rn` — 按數值(`-n`)降序(`-r`)排序 → 出現最多的 IP 排在最上面。

> `uniq -c` 只統計 **相鄰的** 重複行,所以前面一定要先 `sort`。

任務:把請求數最多的 IP **只儲存一個**(只要 IP 字串,不含計數)到 `~/work/top-ip.txt`。用 `head -1` 取出第一行,再用 awk 只提取 IP 欄位即可。

```
awk '{print $1}' /var/log/lab/access.log | sort | uniq -c | sort -rn | head -1 | awk '{print $2}' > ~/work/top-ip.txt
```

- `head -1` — 只保留第一名那一行(`  123 1.2.3.4`)。
- `awk '{print $2}'` — 只取出該行的第二個欄位(IP),再用 `>` 儲存。

儲存好後點選 **[驗證]**。

## 用 sed 做流編輯

這份日誌需要對外共享,但客戶端 IP 屬於個人資訊,必須 **脫敏**。用 sed 的替換(`s/模式/替換/`)來解決。

用正規表示式匹配行首的 IPv4。使用 `-E`(擴充套件正則)就可以直接使用 `{1,3}` 這樣的量詞。

```
sed -E 's/^[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}/REDACTED/' /var/log/lab/access.log | head -3
```

- `sed -E 's/模式/替換/'` — 對每一行,把第一個匹配模式的部分替換後輸出(原檔案不變)。
- `^` — 行首,`[0-9]{1,3}` — 1~3 位數字,`\.` — 點號字元本身。合起來就是行首的 IPv4 地址。

任務:把整個日誌中的 IP 替換為 `REDACTED` 的副本儲存為 `~/work/access-redacted.log`。行數必須與原檔案相同(是替換,不是刪除)。

儲存替換後的副本:

```
sed -E 's/^[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}/REDACTED/' /var/log/lab/access.log > ~/work/access-redacted.log
```

- 對整個檔案做同樣的替換,並把結果儲存為新檔案。要直接修改原檔案可以用 `-i`,但這裡是另存副本。

檢視替換後的行數:

```
grep -c REDACTED ~/work/access-redacted.log
```

- 統計含有 `REDACTED` 的行數,應與 `wc -l` 的結果(原檔案行數)相同。

儲存好後點選 **[驗證]**。

## 管道綜合練習

最後是一個實戰問題:**"請求 /api 路徑且成功(200)的響應,總傳輸量是多少?"**

一條 awk 就能同時完成過濾和彙總 — 用條件表示式篩選行,用變數累加,在 `END` 塊中輸出。

```
awk '$7 ~ /^\/api\// && $9 == 200 {s += $10} END {print s}' /var/log/lab/access.log
```

- `$7 ~ /正則/` — 第 7 個欄位是否匹配正則。正則中的 `/` 要轉義為 `\/`。
- 變數 `s` 無需宣告,從 0 開始。`END` 塊在讀完所有行後執行一次。

拆開來看:

| 片段 | 含義 |
|---|---|
| `$7 ~ /^\/api\//` | 路徑欄位以 `/api` 開頭 |
| `&& $9 == 200` | 並且狀態為 200 |
| `{s += $10}` | 把位元組欄位累加到 s |
| `END {print s}` | 全部讀完後輸出總和 |

任務:把這個總和儲存到 `~/work/api-bytes.txt`,然後點選 **[驗證]**。

```
awk '$7 ~ /^\/api\// && $9 == 200 {s += $10} END {print s}' /var/log/lab/access.log > ~/work/api-bytes.txt
```

- 與上一條命令相同,只是用 `>` 把輸出儲存到檔案。
