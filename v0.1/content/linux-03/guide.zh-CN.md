# 文本处理管道

Linux 运维工作有一半是 **读日志**。用管道把 grep、awk、sed 三个工具串起来,几秒钟就能从几十万行日志里提取出答案。

实验环境中准备了 2,000 行 Web 服务器访问日志。先看看它长什么样。

查看前 5 行:

```
head -5 /var/log/lab/access.log
```

- `head -5 <文件>` — 只输出文件的前 5 行(与 `-n 5` 相同)。

查看总行数:

```
wc -l /var/log/lab/access.log
```

- `wc -l <文件>` — 统计行数(word count 的行选项)。`-w` 统计单词数,`-c` 统计字节数。

一行的结构(按空白分隔的字段编号):

| 字段 | 内容 | 示例 |
|---|---|---|
| $1 | 客户端 IP | `192.168.14.23` |
| $6~$8 | 请求(`"METHOD path HTTP/1.1"`) | `"GET /api/users HTTP/1.1"` |
| $9 | 状态码 | `200` |
| $10 | 响应字节数 | `1532` |

## 用 grep 查找错误

grep 是 **挑出** 匹配模式的 **行** 的工具。来找一下服务器错误(5xx)。简单地用 `grep 500` 会把字节数为 500 的行也匹配进来 — 必须 **只匹配状态码的位置**。

```
grep -E '" 5[0-9]{2} ' /var/log/lab/access.log | head
```

- `grep -E` — 扩展正则表达式。`5[0-9]{2}` 表示以 5 开头的三位数字。
- `'" 5[0-9]{2} '` — 用引号和空格包住前后,只匹配状态码的位置。整体用单引号括起来,避免 shell 解释。

关键在于加入前后文,只匹配 `"` 后面空格之后的 5xx。`-c` 只输出匹配的行数。

任务:把 5xx 错误的行数保存到 `~/work/err5xx.count`。

保存 5xx 行数:

```
grep -Ec '" 5[0-9]{2} ' /var/log/lab/access.log > ~/work/err5xx.count
```

- `-c` — 不输出匹配的行,只输出 **行数**。与 `-E` 合写为 `-Ec`。
- `> ~/work/err5xx.count` — 把这个数字保存到文件。

查看保存的值:

```
cat ~/work/err5xx.count
```

- `cat` — 输出文件内容,确认保存的数字。

保存好后点击 **[校验]**。

## 用 awk 提取字段与汇总

awk 是把行 **拆分成字段** 来处理的工具。`$1` 是第一个字段(IP)。

```
awk '{print $1}' /var/log/lab/access.log | head
```

- `awk '{print $1}'` — 把每行按空白拆分成字段,只输出第一个字段(IP)。`{ }` 中是对每一行执行的动作。

再接上经典的汇总管道 `sort | uniq -c | sort -rn`,就得到了频次表。

```
awk '{print $1}' /var/log/lab/access.log | sort | uniq -c | sort -rn
```

- `sort` — 排序,让相同的 IP 挨在一起;`uniq -c` — 把连续的相同行合并为一行,并在前面加上计数。
- `sort -rn` — 按数值(`-n`)降序(`-r`)排序 → 出现最多的 IP 排在最上面。

> `uniq -c` 只统计 **相邻的** 重复行,所以前面一定要先 `sort`。

任务:把请求数最多的 IP **只保存一个**(只要 IP 字符串,不含计数)到 `~/work/top-ip.txt`。用 `head -1` 取出第一行,再用 awk 只提取 IP 字段即可。

```
awk '{print $1}' /var/log/lab/access.log | sort | uniq -c | sort -rn | head -1 | awk '{print $2}' > ~/work/top-ip.txt
```

- `head -1` — 只保留第一名那一行(`  123 1.2.3.4`)。
- `awk '{print $2}'` — 只取出该行的第二个字段(IP),再用 `>` 保存。

保存好后点击 **[校验]**。

## 用 sed 做流编辑

这份日志需要对外共享,但客户端 IP 属于个人信息,必须 **脱敏**。用 sed 的替换(`s/模式/替换/`)来解决。

用正则表达式匹配行首的 IPv4。使用 `-E`(扩展正则)就可以直接使用 `{1,3}` 这样的量词。

```
sed -E 's/^[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}/REDACTED/' /var/log/lab/access.log | head -3
```

- `sed -E 's/模式/替换/'` — 对每一行,把第一个匹配模式的部分替换后输出(原文件不变)。
- `^` — 行首,`[0-9]{1,3}` — 1~3 位数字,`\.` — 点号字符本身。合起来就是行首的 IPv4 地址。

任务:把整个日志中的 IP 替换为 `REDACTED` 的副本保存为 `~/work/access-redacted.log`。行数必须与原文件相同(是替换,不是删除)。

保存替换后的副本:

```
sed -E 's/^[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}/REDACTED/' /var/log/lab/access.log > ~/work/access-redacted.log
```

- 对整个文件做同样的替换,并把结果保存为新文件。要直接修改原文件可以用 `-i`,但这里是另存副本。

查看替换后的行数:

```
grep -c REDACTED ~/work/access-redacted.log
```

- 统计含有 `REDACTED` 的行数,应与 `wc -l` 的结果(原文件行数)相同。

保存好后点击 **[校验]**。

## 管道综合练习

最后是一个实战问题:**"请求 /api 路径且成功(200)的响应,总传输量是多少?"**

一条 awk 就能同时完成过滤和汇总 — 用条件表达式筛选行,用变量累加,在 `END` 块中输出。

```
awk '$7 ~ /^\/api\// && $9 == 200 {s += $10} END {print s}' /var/log/lab/access.log
```

- `$7 ~ /正则/` — 第 7 个字段是否匹配正则。正则中的 `/` 要转义为 `\/`。
- 变量 `s` 无需声明,从 0 开始。`END` 块在读完所有行后执行一次。

拆开来看:

| 片段 | 含义 |
|---|---|
| `$7 ~ /^\/api\//` | 路径字段以 `/api` 开头 |
| `&& $9 == 200` | 并且状态为 200 |
| `{s += $10}` | 把字节字段累加到 s |
| `END {print s}` | 全部读完后输出总和 |

任务:把这个总和保存到 `~/work/api-bytes.txt`,然后点击 **[校验]**。

```
awk '$7 ~ /^\/api\// && $9 == 200 {s += $10} END {print s}' /var/log/lab/access.log > ~/work/api-bytes.txt
```

- 与上一条命令相同,只是用 `>` 把输出保存到文件。
